# 🎵 Resonance

**Resonance** — это современная, минималистичная и быстрая музыкальная стриминговая платформа, написанная на чистом Go (Standard Library) и Vanilla JavaScript.

Проект создан как легковесная альтернатива крупным сервисам с акцентом на **премиальную темную iOS-эстетику (Apple Music style)**, высокую производительность и отсутствие тяжелых JS-фреймворков.

## 🚀 Ключевые возможности

* **iOS-эстетика и UI/UX:** Плавные анимации, эффект матового стекла (glassmorphism), закругленные элементы интерфейса и всплывающие Toast-уведомления (в стиле Dynamic Island).
* **Плавающий плеер:** Удобный аудиоплеер, который всегда под рукой.
* **Живое Радио (Live):** Встроенная вкладка с популярными радиостанциями (Европа Плюс, Radio Energy, Наше Радио, Шансон) с поддержкой бесконечного потока.
* **Система верификации (Фримиум):** Регистрация с подтверждением по Email (SMTP). Неподтвержденные аккаунты могут слушать только **30 секунд** каждого трека.
* **Продвинутая Студия:** Загрузка треков и обложек, поддержка соавторов (`&`) и приглашенных артистов (`feat.`), отложенные и скрытые релизы.
* **Профили артистов:** Индивидуальные страницы музыкантов с подсчетом прослушиваний.
* **Мощная Админ-панель:**
* Дашборд со статистикой (пользователи, треки, заявки).
* Модерация треков (переименование, скрытие, удаление).
* Управление пользователями (изменение ролей, блокировка/удаление).


* **Живой поиск:** Мгновенная фильтрация медиатеки по названию и автору без перезагрузки страницы.

## 🛠 Технологический стек

* **Backend:** Go (только `net/http` и `net/smtp`, без сторонних роутеров)
* **Frontend:** Vanilla JS, HTML5, CSS3 (CSS Grid / Flexbox / Backdrop-filter)
* **База данных:** In-Memory + JSON (локальные файлы `db.json` и `users.json`)
* **Хранилище:** Локальная файловая система (папки `/storage/audio` и `/storage/covers`)

## ⚙️ Установка и запуск

Убедитесь, что у вас установлен [Go](https://go.dev/dl/).

### 1. Клонирование и инициализация

```bash
git clone https://github.com/yaayex/resonance.git
cd resonance
go mod init resonance

```

### 2. Настройка Email (SMTP)

Для работы системы верификации пользователей серверу нужен доступ к отправке писем.

1. Зайдите в аккаунт Google → Безопасность → Двухэтапная аутентификация.
2. Создайте **Пароль приложений** (16 символов).
3. Откройте файл `main.go`, найдите функцию `sendVerificationEmail` и вставьте свои данные:

```go
from := "ТВОЙ_GMAIL@gmail.com" 
password := "ТВОЙ_ПАРОЛЬ_ПРИЛОЖЕНИЙ"

```

### 3. Запуск сервера

```bash
go run main.go

```

Откройте приложение в браузере по адресу: **http://localhost:8080**

## 👑 Ролевая система и права Администратора

В Resonance реализовано три уровня доступа:

* **Слушатель (Базовый):** Ищет музыку, слушает радио. Без подтверждения почты — лимит 30 секунд на трек.
* **Артист:** Имеет доступ к "Студии" для публикации релизов.
* **Администратор:** Полный контроль над платформой, пользователями и контентом.

**Как получить права Администратора при первом запуске:**

1. Зарегистрируйте аккаунт через интерфейс сайта (например, с логином `admin`).
2. Откройте локальный файл `storage/users.json` в любом текстовом редакторе.
3. Найдите объект вашего пользователя и измените значение поля `"role"` с `"user"` на `"admin"`.
4. Измените `"is_verified"` на `true`, чтобы снять ограничения плеера.
5. Сохраните файл, выйдите из аккаунта на сайте и авторизуйтесь заново.
