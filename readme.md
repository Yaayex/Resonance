# 🎵 Resonance

**Resonance** — это современная, минималистичная и быстрая музыкальная стриминговая платформа, написанная на чистом Go (Standard Library) и Vanilla JavaScript. 

Проект создан как легковесная альтернатива крупным сервисам (Spotify / Яндекс.Музыка) с акцентом на темную эстетику, высокую производительность и отсутствие тяжелых JS-фреймворков.

## 🚀 Ключевые возможности

- **Плавающий плеер:** Красивый аудиоплеер с эффектом матового стекла (glassmorphism), который появляется при включении трека.
- **Ролевая система:** 
  - **Слушатель:** может искать и слушать музыку, формировать медиатеку.
  - **Артист:** имеет доступ к "Студии" для загрузки своих треков и обложек.
  - **Администратор:** управляет заявками на верификацию артистов.
- **Продвинутая загрузка треков:** Поддержка соавторов (отображаются через `&`) и приглашенных артистов (`feat.`).
- **Профили артистов:** Индивидуальные страницы музыкантов с подсчетом общего количества прослушиваний.
- **Живой поиск:** Мгновенная фильтрация треков по названию и автору без перезагрузки страницы.
- **Адаптивный дизайн:** Полная поддержка мобильных устройств с удобным боковым меню.

## 🛠 Технологический стек

- **Backend:** Go (только `net/http`, без сторонних роутеров)
- **Frontend:** Vanilla JS, HTML5, CSS3 (CSS Grid / Flexbox)
- **База данных:** In-Memory + JSON (локальные файлы `db.json` и `users.json` для быстрого прототипирования)
- **Хранилище:** Локальная файловая система (папки `/storage/audio` и `/storage/covers`)

## ⚙️ Установка и запуск

Убедитесь, что у вас установлен [Go](https://go.dev/dl/).

1. **Клонируйте репозиторий:**
   ```bash
   git clone [https://github.com/yourusername/resonance.git](https://github.com/yourusername/resonance.git)
   cd resonance
   ```
Инициализируйте Go-модуль (если еще не создан):

Bash
go mod init resonance
Запустите сервер:

Bash
go run main.go
Откройте приложение:
Перейдите в браузере по адресу http://localhost:8080.

👑 Как получить права Администратора
По умолчанию все новые пользователи регистрируются как "Слушатели". Чтобы выдать себе права администратора при первом запуске:

Зарегистрируйте аккаунт через интерфейс сайта (например, с логином admin).

Откройте файл storage/users.json в текстовом редакторе.

Найдите своего пользователя и измените значение поля "role" с "user" на "admin".

Сохраните файл, выйдите из аккаунта на сайте и войдите заново.
